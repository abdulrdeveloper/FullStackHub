# ☕ Starbucks Landing Page

This is a front-end **landing page project inspired by Starbucks**, built entirely with **HTML and CSS**. It includes branding, navigation, product visuals, call-to-action buttons, and interactive hover effects.

> ⚠️ Note: This layout is **partially responsive**. It is optimized for **desktop view** but includes some support for tablet and mobile screens via media queries.

---

## ✅ Features

- Visually inspired by Starbucks product marketing  
- Custom background design using `::before` and gradients  
- Dropdown-style navigation bar  
- Hover animation on thumbnails  
- Font Awesome icons for social media  
- Circular background design using `conic-gradient`  
- Fully front-end (no JavaScript, no backend)

---

## 📁 Project Structure

All files must stay inside a **single folder** to work correctly.
