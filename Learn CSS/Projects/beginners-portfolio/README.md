# Abdul Rahman Portfolio

Live: https://abdulr-portfolio.netlify.app

This is a simple personal portfolio website built with HTML and CSS. It is made to show your work, services, resume, and contact details in a clean and professional way.

## What is included
- Home page
- About page
- Services page
- Portfolio page
- Resume page
- Blog page
- Contact page

## Project structure
- index.html — main homepage
- pages/ — all extra pages
- assets/css/style.css — main stylesheet
- assets/images/ — images used on the site
- assets/docs/ — downloadable files like the CV
- private/ — place private or sensitive files here

## How to run locally
1. Open the project folder.
2. Start a simple server.
   - If you use Python, run:
     python3 -m http.server 8000
3. Open your browser and go to:
   http://127.0.0.1:8000

## How to customize
- Change text directly in the HTML files.
- Change colors and layout in style.css.
- Replace images in assets/images/.
- Add new pages in pages/ and link them from the navigation.

## Notes for beginners
- This project is easy to edit.
- Keep private files in private/.
- If you publish the site online, make sure all links and image paths still work.
