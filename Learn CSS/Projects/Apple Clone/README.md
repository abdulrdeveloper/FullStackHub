# 🍎 Apple Clone – Product Page

A clean and fully responsive front-end **Apple product page clone**, built entirely using **HTML and CSS**.

This project closely resembles the real Apple website layout and includes:

✅ Full Header to Footer Layout  
✅ Dropdown Navigation Menu  
✅ Smooth CSS Animations  
✅ Responsive Design (Desktop & Mobile View)

> 📌 No JavaScript or back-end functionality — purely front-end.

---

## 📁 Project Structure

All required files are placed in **a single folder**, including:

- `index.html`  
- `style.css`  
- Image files (e.g., logos, banners)  
- Favicon/icon files

⚠️ **Important:**  
To ensure the project works correctly, **do not move files to subfolders**. Keep everything in **one folder** as structured.
