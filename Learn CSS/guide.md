# CSS Guide

## What is CSS?
CSS stands for Cascading Style Sheets.
It is the language used to style web pages.
It controls things like colors, spacing, fonts, layout, and responsive design.

## Why do we use CSS?
We use CSS to:
- make websites look nice
- control the layout of a page
- change colors, fonts, and spacing
- make pages responsive on different screen sizes

CSS works with HTML to turn simple structure into a good-looking website.

## How to use CSS
1. Create a file with the .css extension.
2. Link the CSS file to your HTML file.
3. Write your styles using selectors and properties.
4. Open the page in a browser to see the design.

## Best practice tips
- Keep your CSS clean and organized.
- Use meaningful class names.
- Avoid repeating the same code again and again.
- Use flexbox and grid for layout.
- Make your design responsive for mobile and desktop.

1. Learn basic CSS syntax.
2. Practice selectors, colors, and text styling.
3. Learn box model, margin, and padding.
4. Practice flexbox and grid.
5. Build small responsive pages using CSS.
