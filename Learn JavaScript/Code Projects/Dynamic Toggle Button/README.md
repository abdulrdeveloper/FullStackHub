# Dynamic Toggle Button - Day & Night Mode

A simple and beautiful toggle button that switches between light mode (day) and dark mode (night). Click the button to toggle between modes and see smooth animations and inspiring messages.

## Features
- 🌞 **Light Mode**: White background with sun icon and motivating day message
- 🌙 **Dark Mode**: Black background with moon icon and peaceful night message
- ✨ Smooth animations and transitions
- 💻 Pure HTML, CSS, and JavaScript (no dependencies except Font Awesome icons)

## How to Clone
```bash
git clone https://github.com/abdulrdeveloper/Dynamic-Toggle-Button.git
cd "Dynamic Toggle Button"
```

## How to Use
1. Open `toggle-button.html` in your browser (just double-click the file)
2. Click the sun/moon button to toggle between day and night modes
3. Watch the background, text, icon, and message change smoothly
4. That's it! No setup needed!
