# 📝 CRUD Notes App - RESTful API

A clean, modular RESTful API built with **Node.js**, **Express 5**, and **MongoDB (Mongoose)** for managing personal notes. It provides complete Create, Read, Update, and Delete (CRUD) capabilities with proper validation, Mongoose timestamps, and environment-based configuration.

---

## 🚀 Features

- **Full CRUD Functionality**: Create, read all, update, and delete notes.
- **Data Persistence**: Backed by MongoDB with Mongoose object data modeling (ODM).
- **Schema Validation & Sanitization**: Trims whitespace and enforces required fields (`title`, `description`).
- **Automatic Timestamps**: Tracks `createdAt` and `updatedAt` for every note entry.
- **Modern ES Modules**: Written using native ES Module syntax (`import`/`export`).
- **Configurable Environment**: Managed securely using `dotenv`.

## ⚙️ Environment Variables

Create a `.env` file in the root of `crud-notes-app` by copying `.env.example`:

```bash
cp .env.example .env
```

Define the following environment variables:

| Variable | Description | Example |
| :--- | :--- | :--- |
| `PORT` | The port on which the Express server listens (default: `3000`) | `3000` |
| `MONGO_URI` | MongoDB connection URI (local or MongoDB Atlas cluster) | `mongodb://127.0.0.1:27017/notes-db` |

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [MongoDB](https://www.mongodb.com/try/download/community) installed and running locally, or a [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) connection URI
- [pnpm](https://pnpm.io/) or [npm](https://www.npmjs.com/)

### Installation

1. Navigate to the project directory:

   ```bash
   cd "backend best collection/crud-notes-app"
   ```

2. Install the dependencies:

   ```bash
   # Using pnpm
   pnpm install

   # Or using npm
   npm install
   ```

3. Set up your `.env` file with your MongoDB connection string:

   ```env
   PORT=3000
   MONGO_URI=mongodb://127.0.0.1:27017/notes-db
   ```

4. Start the server:

   ```bash
   # Development mode (with automatic reload on file changes)
   npm run dev

   # Production / standard start
   npm start
   ```

5. Once connected, you will see:
   ```text
   Connected to Database
   Server is running on port 3000
   ```

## 📋 Data Model

The `Note` schema is structured as follows:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `_id` | `ObjectId` | Auto | Unique identifier generated by MongoDB |
| `title` | `String` | Yes | Title of the note (automatically trimmed) |
| `description` | `String` | Yes | Body content / details of the note (trimmed) |
| `createdAt` | `Date` | Auto | Timestamp when the note was created |
| `updatedAt` | `Date` | Auto | Timestamp when the note was last updated |

## 📡 API Endpoints

### Summary

| Method | Endpoint | Description | Status Code |
| :--- | :--- | :--- | :--- |
| `POST` | `/notes` | Create a new note | `201 Created` |
| `GET` | `/notes` | Retrieve all notes from database | `200 OK` |
| `PATCH` | `/notes/:id` | Update an existing note by ID | `200 OK` |
| `DELETE` | `/notes/:id` | Delete a note by ID | `200 OK` |

---

### Endpoint Details & Examples

#### 1. Create a Note

- **URL**: `/notes`
- **Method**: `POST`
- **Headers**: `Content-Type: application/json`
- **Body**:
  ```json
  {
    "title": "Study Node.js Streams",
    "description": "Learn readable, writable, duplex, and transform streams in Node.js."
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "message": "Note created successfully"
  }
  ```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/notes \
  -H "Content-Type: application/json" \
  -d '{"title": "Study Node.js Streams", "description": "Learn readable, writable, duplex, and transform streams."}'
```

---

#### 2. Get All Notes

- **URL**: `/notes`
- **Method**: `GET`
- **Response** (`200 OK`):
  ```json
  {
    "message": "Notes fetched successfully",
    "notes": [
      {
        "_id": "664b3a1a4f1a25d3a8123456",
        "title": "Study Node.js Streams",
        "description": "Learn readable, writable, duplex, and transform streams in Node.js.",
        "createdAt": "2026-09-04T06:30:00.000Z",
        "updatedAt": "2026-09-04T06:30:00.000Z",
        "__v": 0
      }
    ]
  }
  ```

**cURL Example**:
```bash
curl -X GET http://localhost:3000/notes
```

---

#### 3. Update a Note by ID

- **URL**: `/notes/:id`
- **Method**: `PATCH`
- **Headers**: `Content-Type: application/json`
- **Body** (pass fields you want to update):
  ```json
  {
    "description": "Updated note description with more details."
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "message": "Note updated successfully"
  }
  ```

**cURL Example**:
```bash
curl -X PATCH http://localhost:3000/notes/664b3a1a4f1a25d3a8123456 \
  -H "Content-Type: application/json" \
  -d '{"description": "Updated note description with more details."}'
```

---

#### 4. Delete a Note by ID

- **URL**: `/notes/:id`
- **Method**: `DELETE`
- **Response** (`200 OK`):
  ```json
  {
    "message": "Note deleted successfully"
  }
  ```

**cURL Example**:
```bash
curl -X DELETE http://localhost:3000/notes/664b3a1a4f1a25d3a8123456
```

## 🧪 Testing with Postman or Thunder Client

You can test all endpoints using tools like [Postman](https://www.postman.com/) or the [Thunder Client VS Code extension](https://www.thunderclient.com/):

1. Set request method (`GET`, `POST`, `PATCH`, `DELETE`).
2. Enter the URL: `http://localhost:3000/notes` (or append `/:id` for specific notes).
3. Under the **Headers** tab, ensure `Content-Type: application/json` is present for `POST` and `PATCH`.
4. Under the **Body** tab, select **raw** > **JSON** and send the request payload.
